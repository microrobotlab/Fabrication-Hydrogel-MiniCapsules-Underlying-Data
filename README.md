Folder "images": set of images used for the data analysis reported in the paper.
Acquired using a Hirox microscope (model: HRX-01)
Magnification, objective, camera settings and light conditions used are reported in the legend on the images.

The data.CSV file contains the dimensions measurements acquired from these images with the microscope software.

The two files Software_ThicknessAnalysis.jl and Functions_ThicknessAnalysis.jl are the Julia scripts that we used for analyzing these data, the first calling the functions written in the second.
